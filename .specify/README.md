# Spec Kit usage in Golam

This repository follows GitHub Spec Kit's agentic specification-driven development workflow.

Planning baseline inspected: `github/spec-kit` main at commit `27f50f7e6b618ea14d74dd4037f9e7c60218b16c` (Spec Kit 1.0.1 release line; 2026-08-21).

Golam uses the workflow:

`constitution -> specify -> clarify -> plan -> checklist -> tasks -> analyze -> implement -> converge`

The project is currently through the planning/checklist stage for Spec 001. `tasks.md` is intentionally absent until the required external GLM 5.3 architecture review is completed and accepted.

The canonical governance source is `.specify/memory/constitution.md`. Feature artifacts live under `specs/` and are version controlled.
