# Golam

Golam is a local-first autonomous Agent OS for your computer.

The project is Rust-first and is designed so the user's computer, models, memory, tools, policies, and execution history remain locally owned by default. Cloud inference and external channels are optional capabilities, never the trust root.

Golam is developed through governed GitHub Spec Kit specifications, exact-head verification, independent review, and evidence-backed closeout. The model may propose actions, but authority remains outside model reasoning.

## Strategic direction

The current strategic roadmap candidate is:

- [`roadmap/golam-agent-kernel-roadmap-v2.md`](roadmap/golam-agent-kernel-roadmap-v2.md) — six-plane Agent Operating Kernel architecture, capability plane, durable evidence receipts, evidence-backed context/memory, long-running work, future program decomposition, and GolamBench v2.
- [`roadmap/reference-agent-systems.md`](roadmap/reference-agent-systems.md) — reference-only research corpus and Source Foundry reuse boundary.

These roadmap documents do not widen an active canonical specification by themselves. Accepted changes become authority only through the repository's normal specification, exact-head CI, independent review, guarded merge, and post-merge verification lifecycle.
