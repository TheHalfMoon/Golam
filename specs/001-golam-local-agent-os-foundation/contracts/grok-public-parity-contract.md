# Contract: Grok Bot Public Feature Parity

## Purpose

Track Golam against publicly documented/observable Grok Bot behaviors without copying proprietary internals.

## Parity states

- `NOT_RESEARCHED`
- `RESEARCHED`
- `SPECIFIED`
- `IMPLEMENTED_UNVERIFIED`
- `VERIFIED_EQUIVALENT`
- `VERIFIED_SUPERSET`
- `NOT_APPLICABLE_WITH_RATIONALE`

## Required record per feature

- public source/evidence;
- normalized capability statement;
- privacy/security implications;
- Golam requirement/spec reference;
- implementation reference;
- verification scenario;
- exact tested version/head;
- parity state;
- known differences.

## Initial domains

- named persistent agents/workers;
- persistent computer/workspace;
- browser/files/terminal/app use;
- local-computer execution;
- long-running/background operation;
- memory and cross-session continuity;
- parallel agents;
- groups/collaboration/handoffs;
- approvals and security controls;
- skills/plugins/marketplaces;
- MCP/connectors;
- schedules/routines/automations;
- teach-by-demonstration/reusable routines;
- artifacts/files and rich outputs;
- Desktop/mobile continuity;
- built-in Documents/Presentations/Spreadsheets/PDFs/Skill Creator skill categories.

Parity is a release-evidence program, not a justification for copying names, assets, source, prompts, or private behavior.
